
# Attendance & Performance Tracking System

This repository contains an employee operations system with separate areas for frontend, backend, and testing work.

## Repository Areas

- `frontend/` for the user interface
- `backend/` for API, authentication, business logic, and data access
- `testing/` for test planning and validation artifacts

## Backend Documentation

The backend is the strongest part of this repository for screening and portfolio use.

- Backend overview: [backend/README.md](/d:/Git/attendence-performance-tracking/backend/README.md)
- API reference: [backend/docs/API_REFERENCE.md](/d:/Git/attendence-performance-tracking/backend/docs/API_REFERENCE.md)

## Project Goal

The system is designed to manage:

- departments and employees
- attendance sessions and attendance records
- performance metrics and evaluation records
- role-based access across admin and manager workflows

## Contribution Notes

This repository is split by responsibility:

- `frontend/` for UI work
- `backend/` for API and server logic
- `testing/` for validation artifacts

If multiple contributors are working on the repository, keep changes scoped to the relevant area and use clear, descriptive commits.
